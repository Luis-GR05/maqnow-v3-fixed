# MAQNOW — checklist de lanzamiento

## DNS
- [ ] Registrar dominio definitivo.
- [ ] Añadir el dominio al proveedor de hosting.
- [ ] Crear los registros A/AAAA/CNAME exactamente con los valores que entregue el hosting.
- [ ] Configurar `www` → dominio canónico.
- [ ] Activar HTTPS y redirección HTTP → HTTPS.
- [ ] Elegir una única versión canónica: `https://maqnow.es` (placeholder hasta definir dominio).
- [ ] SPF/DKIM/DMARC solo cuando exista correo corporativo.
